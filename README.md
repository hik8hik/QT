# @quranbrain

Neomorphic Quran reader + Script Studio.

## Routes

    /                                Scroll mode (Surah 24)
    /?chapter=36                     Surah Yaseen
    /?view=page&chapter=2&ayah=186   A single ayah
    /?view=mushaf&page=50             Mushaf page (perfect 15-line fit)
    /settings                        Legacy — now a floating drawer
    /script                          Script Studio

## Features added

- Floating settings drawer (never lose your place)
- Verse search ("2:186") in the header
- Perfect 15-line Mushaf auto-fit
- 9:16 4K and 8K Mushaf exports (page + frame only)
- Text outline (stroke) option for reader and script studio
